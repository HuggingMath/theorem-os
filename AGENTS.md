# Standalone mathematics runtime

Keep the CLI and mathematics proof behavior independent of the original DeepScientist checkout. The optional `apps/web` workbench is a separate BYOK HTTP service and Docker supervisor; it must not become a dependency of the CLI or mathematics services. There is no Electron or desktop build.

`src/math` owns mathematics services. `src/solver/run.ts` prepares and evaluates proof runs, `src/solver/research.ts` runs researcher sessions with shared budgets and checkpoints, and `src/solver/agentTeam.ts` connects Codex collaboration to isolated proof writers and checked handoffs. Codex Lead assigns responsibilities using the pinned Skill. `src/solver/archive.ts` owns S1 records and `src/solver/evaluation.ts` owns fixed S3 final acceptance. `src/runtime/codexSession.ts` connects to Codex through stdio. Keep historical collaboration records readable. Resume and reproduce retired host scheduling workflows with their pinned historical runtime. Do not reintroduce the original Core, Team services, HTTP services, role queues, or MCP orchestration into the runtime. S2 learning remains a future extension.

Preserve frozen problem/source identities, isolated solver worktrees, Lean receipts, independent evaluation, and resumable runs. A model's completed message is never proof acceptance.

New formalization requests and proof runs default to `high` reasoning. Web records can freeze a separate `researchEffort`; explicit effort selections, saved drafts and frozen tasks retain their configuration, including `max`. Older records without this field inherit their original effort; CLI resumes without `--effort` keep their frozen effort. Both use `deepseek-flash` through the local sub2api gateway (`http://127.0.0.1:8080/v1`) and the profile at `~/.config/deepscientist/math-sol-codex`. This local profile uses an auth command to read the existing Sub2API Westlake pool key; generated per-attempt Sub2API profiles require `SUB2API_WESTLAKE_API_KEY`. The previous direct Westlake profile is preserved as `~/.config/deepscientist/math-sol-codex-westlake`, and the `my_codex` / `gpt-6.1-sol` profile as `~/.config/deepscientist/math-sol-codex-my_codex`, for resuming older runs via `CODEX_HOME`. Do not copy credentials, alter global Codex configuration, or call real models merely to validate a local extraction.

Make the smallest requested change. Run focused tests and the headless bundle build when modifying runtime boundaries. Do not commit, publish, or modify the original checkout without an explicit request.
