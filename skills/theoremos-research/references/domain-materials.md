# Mathematical domain materials

This collection supplies subject knowledge for the [domain experts](domain-experts.md). Each role's **Reading** link opens the relevant section below. Read the knowledge summary and the source location that fits the question; the member chooses its reasoning and proof approach.

The notes name the author and work, link the original, identify chapters, sections or PDF pages, summarize the knowledge in original wording and state the portion covered. Source identities and summaries refer to passages actually read for this collection. Assigning that coverage to a role is a curation judgment; a role's full subject can extend beyond its collected passages.

Each role has **Further reading** for a focused specialist topic. Each reading keeps its own scope: the first entry describes the initial passage, while later entries extend its coverage. These additions include substantive results and their hypotheses as well as definitions. Coverage varies by topic and does not amount to a complete subject library. Read the section matching the knowledge needed for the current question.

The original texts keep their authors' and publishers' terms. This Skill contains source links and original knowledge notes, with any specifically stated reuse limits. Public availability alone does not establish an open redistribution licence. PDF page numbers count from the start of the linked file when identified as PDF pages; printed page numbers can differ, and preprints can differ from published editions.

The notes are included in the pinned Skill and remain readable without network access. Full third-party downloads and retrieval snapshots are maintained separately for source verification; their host paths are not part of the solver's projected workspace. Open originals only when the run permits the required network access. An inaccessible original remains an explicit source limit.

For a theorem application, read the exact statement and assumptions in context using [literature.md](literature.md). Mathematical text does not establish that the pinned Lean library contains the corresponding declaration; [lean.md](lean.md) covers the actual formal interface. The frozen problem, source ownership and independent acceptance rules continue to apply.
