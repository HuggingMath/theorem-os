# 0006 — 数学工具先在本地原生团队验收

首轮在本地新版 Lead 和子 Agent 上验收选用数学工具、执行命令和使用结果。可选扩展配置已经安装在本机，可以直接观察工具在成员工作区里是否可用、结果是否到达使用者。另一种选择是首轮同时验收 Web；容器需要自行安装工具及其运行依赖，留待单独处理。

本地结论只适用于受测配置和命令。脚本指定工具后成功执行，可以验证原生协作链路，不能据此认定模型会自主选择同一工具，或认为整题已通过 Lean 验收。
