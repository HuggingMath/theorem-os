## 数学条目和两个目标

固定实际声明 `one_div_lt_one_div_of_lt`，来自 Mathlib `db584cd6d46c92f209a44c0f1c829460d327499d` 的 `Mathlib/Algebra/Order/Field/Basic.lean:72`。保留完整源文件、完整类型、隐式参数、`Semifield / PartialOrder / PosMulReflectLT` 前提、Apache-2.0 许可证和原作者信息，见 [case.json](../../examples/knowledge-reuse/reciprocal/case.json)。

| 项目 | 成功分支 | 前提不足分支 |
| --- | --- | --- |
| 局部前提 | `a b : ℝ, ha : 0 < a, hb : 0 < b` | `a b : ℝ, ha : 0 < a, hb : 0 ≤ b` |
| 完整结论 | `1 / (a + b) < 1 / a` | 相同严格结论 |
| 适配 | 条目参数为 `x = a, y = a + b` | 相同适配 |
| 剩余义务 | `a < a + b` 由严格正性闭合 | 不能从 `0 ≤ b` 得到所需 `0 < b` |
| 原源码结果 | Lean 编译退出 0 | Lean 编译退出 1，明确参数类型不匹配 |
| 闭合表达式检查 | `elaborated`，常量输出包含所选声明 | `failed`，不输出成功引用结论 |

另有独立 Lean 反例：`a = 1, b = 0` 满足弱前提，却使严格结论成为 `1 < 1`；任意 `a` 的零边界和弱化全称命题的否定也已编译通过。没有改用较弱不等式替代原目标。

固定包摘要为 `d258ac8d9a9a6ff72a4576d9fddf6d403519e022ecbb1077856a4f60132d321c`。两条目标各有源码/闭合类型/表达式/环境摘要；Math Card、搜索、尝试和检查从同一份案例对象读取版本。
