## 五个动作的现有入口

| 动作 | 入口 | 输出和使用边界 |
| --- | --- | --- |
| 构建知识目录 | `bun bin/math.ts knowledge build`；[CLI](../../scripts/mathematics/theoremKnowledge.ts)、[冻结存储](../../src/solver/theoremKnowledgeStore.ts) | 显式读取归档或run state，生成全新V2 manifest、同名objects目录、摘要和导入报告；不隐式编译或启动求解 |
| 检索 | `knowledge search`；[检索实现](../../src/solver/theoremKnowledgeSearch.ts) | 按固定目录、关键词和完整目标上下文返回候选；排名不是当前适用性证明 |
| 读取固定材料 | `knowledge get --metadata`、`get --source FILE`、`source`；[元数据](../../src/solver/theoremKnowledgeMetadata.ts)、[源码读取](../../src/solver/theoremKnowledgeSource.ts) | 元数据提供完整字段或续读句柄；get-source返回完整归档文件，source仅返回精确片段。材料读取核对摘要 |
| 当前应用检查 | `check-lean --workspace DIR --file FILE --context DECL --type TYPE --expression TERM`；[CLI](../../scripts/mathematics/checkLean.ts)、[应用检查](../../src/solver/knowledgeApplications.ts) | 在固定且擦除本地证明体的快照中检查闭合表达式；`elaborated` 属advisory，固定 `proofAcceptance: not-assessed` |
| 完整原题验收 | [evaluateSolverProof](../../src/solver/evaluation.ts)，由[runSolver](../../src/solver/run.ts)调用 | 独立主工作区接入精确候选，重检全部原题并核对commit/sourceDigest；Lean-Eval另走官方comparator。没有独立evaluate-only CLI，普通run可能调用研究模型，本轮未运行 |

安装模块的 `library-catalog build/inspect/search/select` 与归档知识V2是两种格式，不能互换。宿主库配置开启时，历史build/enrich/pack被禁用，应通过 `scripts/mathematics/prepareLibraryKnowledge.ts` 准备授权目录；读取时提供workspace与冻结回执。

以下命令在本轮目录可直接读取已生成的固定材料。生成新目录时，build的输出和报告必须使用未存在的路径；不要覆盖本轮冻结目录。

```bash
CATALOG=/home/lzh/workspace/outputs/theoremos-e01-baseline-20261111/catalog.json
DIGEST=4552a174e9ba07fd71cbca27c741bf1595e479a8d67f220b281eba8ee5f7b07e
ENTRY=0004505d6cba32d35e0deb94719bee757eda0615846e696e05e7530360eeb041
bun bin/math.ts knowledge stats --catalog "$CATALOG" --sha256 "$DIGEST"
bun bin/math.ts knowledge search --catalog "$CATALOG" --sha256 "$DIGEST" \
  --query 'Submission.Helpers.disjoint_union_pair_count' --limit 5
bun bin/math.ts knowledge get --catalog "$CATALOG" --sha256 "$DIGEST" \
  --id "$ENTRY" --metadata --max-bytes 16000
bun bin/math.ts knowledge get --catalog "$CATALOG" --sha256 "$DIGEST" \
  --id "$ENTRY" --source Submission/Helpers.lean
```

需要分页时沿 `nextOffset` 拼接，结构化字段拼接完成后再解析。完整命令与源码逐字节读取核对见[目录命令链](/home/lzh/workspace/outputs/theoremos-e01-baseline-20261111/commands/catalog-readback.json)。
