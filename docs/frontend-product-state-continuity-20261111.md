# 前端编辑与状态接续修复 · 2026-11-11

对应[本轮产品审查](../out/product-audit-post-continuity-20261111/report.md)的 8 项缺口，补齐候选修订、个人笔记、费用、待办和账号草稿的接续。修复适用于所有符合条件的题目，沿用现有品牌与配色。

## 完成的行为

| 缺口 | 修复后的行为 |
| --- | --- |
| L2：准备候选后继续修订，刷新丢失修改 | 保存声明、证明体、参数说明和缺失前提；按账号、成果摘要、候选与精确任务版本隔离。刷新恢复修改，切换目标保留各自草稿。存储失败时提示、支持重试，并保护仍未保存的内容。恢复内容需要重新准备与确认检查。 |
| N2：迟到读取覆盖个人整理 | 置顶、状态、标签和接续笔记分别记录是否已编辑。首次读取和失败后重读只填充未编辑字段，使用最新记录的版本保存。 |
| N1：自然语言草稿存储失败无提示 | 实际保存失败时显示状态，可下载完整原题或重试；刷新、关闭前提示。恢复存储后可保存并正常刷新恢复。 |
| B3：跨币种历史费用遗漏 | 累计投入分别列出 CNY、USD 等支持币种的已计价记录；明确金额余额只扣除预算币种，不混加、不自动换汇。 |
| B2：改写复用源码后费用面板消失 | 源码或环境不再匹配原题时，显示本次费用估算和单价入口；恢复精确原题后显示累计规划。修正币种控件被表单重绘重置的问题，实际单价修改能更新估算。 |
| OV1：首页待办责任与候选状态不符 | 首页复用消息中心的实际评审责任与生命周期。等待他人评审的作者不再收到错误待办；评审、补充和重新分配分别交给当前负责人；撤回后移除待办。 |
| L1：关注的旧版本撤回后无法比较 | 比较区解释旧基线不可用，保留当前版本入口。有其他有效版本时允许明确选择比较起点，地址和刷新状态同步更新。 |
| N3：账号草稿丢失分享来源 | 跨设备保留来源标题、摘要和本人可访问的引用。恢复时核对来源，撤回或不可访问时解释原因，保留已保存原题供继续编辑。 |
