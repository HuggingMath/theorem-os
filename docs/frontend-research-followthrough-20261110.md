## 完成的体验

1. **例题替换可恢复。** 自然语言入口保留被替换的原题及研究配置，多次选择例题、刷新后都能恢复；不启动研究，不保存 API Key。
2. **新题 Enter 换行。** 新题编辑使用按钮或明确提示的 Ctrl / ⌘ + Enter 提交。中文输入法确认、手机换行不提交；已有聊天发送习惯保留。
3. **Library 登录接续。** 登录或注册后恢复明确选定的固定版本与组合。收藏返回原版本、展开并定位表单，仍需明确保存。首次入口参数在工作台归一化地址之前捕获。
4. **步骤讨论保留历史上下文。** 保存 run、陈述、task/version、观察时点和源码 commit；步骤名称由服务器从相应保存时点派生。讨论可按节点找回并回到原推导，保持只读讨论语义。账号草稿归档也核对同一引用。
5. **个人批准可继续核对。** 发送前按账号、运行保存原命令 ID 与计划版本；刷新和切页返回先读取回执，不自动再发。明确重试仍用同一 ID，计划变化不会改投到新版本，拒绝后需要重新核对。
6. **首次原题账号草稿。** 自然语言和 Lean 草稿可命名保存，跨设备恢复，保留模型、环境、预算以及 Lean 使用的固定 Library 版本。复用已有账号版本与冲突保留，恢复不启动研究，不保存 Key 或续跑执行身份。编辑后及时显示未保存状态，存储字段排序不会造成误报。
7. **来源导航匹配权限。** 可分别进入自己的来源运行、获授权项目的固定步骤或已公开结果；无权限时只保留可公开的源码、声明和检查记录，不提供必然失败的运行链接。
8. **研究页延续浏览器提醒。** 工作台、题目页及其他登录后的研究页面复用通知偏好。运行结束、计划等待批准时更新通知和标签标题；同账号同事件跨页面去重，点击回到对应运行。邮件渠道保持原实现。
9. **统一项目成员身份。** 项目内显示成员姓名和角色，成员列表、交接与评审选择器一致。角色可在成员行调整。私有完整档案仍不公开，撤权后仍按权限隐藏相关内容。
