# 前端研究流程补全 · 2026-11-10

本轮补齐产品审查中的八项缺口，并加入提交前的 TeX 预览，共九项。改动位于 `feat/product-continuity`，以上一轮 `research-completion` 的实际文件为基础；本会话未提交、推送、合并或部署。

## 已完成的用户流程

| 项目 | 可以实际完成的操作 | 结果与边界 |
| --- | --- | --- |
| 经典题库返回工作台 | 从中英文题目详情点击“准备自己的研究”，到达工作台并返回来源题目 | 动态生成的链接也使用正确路径；保留现有草稿，不自动提交 |
| 运行状态与恢复 | 在题目总览查看排队、运行、等待审阅、失败和停止原因，进入对应处理动作 | 没有路线时仍有真实状态；恢复前再次核对当前操作，只准备草稿或打开诊断 |
| 可读检查诊断 | 从当前路线或全局轨迹查看失败反馈，定位受检源码行，对比前一保存版本 | 优先展示诊断与源码，原始回执折叠；检查仍绑定原任务版本和源码 |
| 单次尝试的演变 | 选择保存时点，查看当时的路线、推导、源码和检查，再返回当前记录 | 刷新、前后退、视图切换和登录保留时点；历史记录不借用后来的验收结果 |
| 首次研究费用预估 | 在第一次运行前设置所选模型综合单价、币种，保存到账号并调整预算 | 形式化和证明分别估算；精确区分模型、零价和未填单价；Lean 输入可直接设置 Token 上限 |
| 围绕步骤查找 Library | 从固定步骤查看目标、前提、环境和关键词，筛选成果并返回原路线 | 匹配理由来自实际文字和声明；相似度不代表已经证明适用，仍需候选检查 |
| 私人项目邀请 | 创建单人邀请链接；新同事登录或注册后核对角色并接受；邀请人可撤销 | 不要求公开个人主页；成员加入不扩大原有运行授权，链接不可被第二人接受 |
| 分享后的收藏与继续研究 | 登录后回到原分享，收藏进私人资料夹，明确确认后准备自己的研究 | 收藏重查分享权限；撤销后保留私人备注。已经确认复制的原题草稿归接收者，使用自己的配置并重新验证 |
| 提交前 TeX 预览 | 在原题输入区切换编辑与公式预览，再回到原文编辑 | 沿用现有数学渲染；保留原输入，不调用模型，也不创建研究 |

另修正实际回归中发现的手机端分享确认框溢出、经典题库来源提示挤占工作区布局，以及工作台研究计数缺少间距的问题。既有品牌颜色与页面结构保持原有约定。
