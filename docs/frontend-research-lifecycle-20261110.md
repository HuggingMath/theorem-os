# 前端研究流程收尾 · 2026-11-10

本轮对应 `out/product-audit-post-followthrough-20261110/report.md` 的 10 项缺口，以及离线 HTML 简报字体建议。保持现有配色与页面结构，补齐草稿、提交回执、交接、评审与资料整理的接续流程。

## 原题草稿

- 明确新建题目时解除上一题的账号草稿绑定；改名、刷新继续使用同一条版本链。
- 保存版本的比较基线随页面恢复。修改原题、名称或配置后，继续提示尚未保存到账号。
- 自然语言和 Lean 两个入口在收到真实任务记录后，关联并归档对应的原题版本。服务端核对所属账号、原题和配置，不凭前端声明标为已提交。
- Lean 归档校验遵循提交接口对源码首尾空白及任务说明的规范化，避免正常提交被误判为内容不一致；账号草稿保留原文。
- 提交期间修改或并行保存的版本分别保留；结果未知或请求被拒绝时不猜测成功。归档同步失败可以接着同步原任务。
- 工作台默认展示未完成版本，历史筛选明确区分已提交和已丢弃。已提交版本可以回到原任务，也可以用原题另起一题。

## 人工指导、交接和独立评审

- 人工指导保存原提交 ID、固定目标、原文和草稿快照。刷新后先查询原回执，明确重试沿用同一 ID；目标版本变化后不向新版本重发。
- 正式交接按账号、项目、运行和任务保留本机说明及接手人。任务版本或成员权限变化时保留文字，要求核对后再发送；成功只清理此次提交的草稿。
- 独立评审不再把作者当作默认评审负责人。没有合格评审人时显示待分配，提供成员管理入口，并带着原候选返回继续分配。

## 官网反馈与资料整理

- 官网反馈在当前标签页保留类型、位置、标题、正文和环境，刷新或切换中英文后恢复。预览、复制、下载、打开 GitHub 均保留草稿；清空可取消，存储失败明确提示。
- 资料夹选择进入地址，支持刷新、页面返回、复制地址和另一个窗口继续查看。指定资料夹不可用时说明原因。
- 删除资料夹前显示名称、收藏数及私人备注数，允许取消，并按已确认的版本执行删除。
- 导出的 HTML 简报内嵌实际使用的 WOFF2 字体与 Unicode 子集，保留 UTF-8 编码和手机页边距。字体读取失败会报告导出失败。
