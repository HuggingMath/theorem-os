## 行为变化

- `SESSION-R6`：研究页初次加载也响应账号离开通知；同一账号的新登录以 CSRF 代次取消旧请求，保留同账号组件和输入。被代次更新中断的资源读取使用新绑定恢复，旧账号组件仍随账号切换卸载。启用登录时，普通响应不再重写身份 Cookie；迟到的旧响应即使先于页面身份确认交付，也不会覆盖新登录。登录时写入的浏览器标识最长保留 365 天，服务端仍按原配置执行闲置过期、退出及撤权；匿名模式保持原有续期行为。
- `COL6-D01`：公开题目的非成员选择成员范围留言后，自己仍能查看和追踪该留言；界面说明作者也可读。既有成员隐私与撤权规则保留，提交不被强制改成公开。
- `COL6-D03`：候选证明提供提交源码、精确基准、差异以及对应的独立检查回执。读取按反馈和运行权限校验，使用保存的候选身份，不替换成运行的当前源码或最新检查。
- `LIB-R6-01`：创建期间继续输入时，成功回包保留编辑器和较新的内容；下一次保存更新刚创建的同一资产。没有后续修改时仍进入详情页。
- `LIB-R6-02`：成功响应的 JSON 无法解析时显示可读提示，保留原请求身份；未改输入的再次提交通过原请求重放恢复，不再重复创建草稿。
- `ROUTE-R6-01`：打开路线图证据前收起全屏画布，使源码栏可见、可操作；关闭后焦点返回路线图的证据入口。
- `COL6-D02`：讨论显示已保存的陈述版本，并允许跳回对应版本；继续保留讨论属于整个定理的范围。

既有 `test-web-natural-first.ts` 的首页清空断言与当前明确的交互合同不符。回归改为验证“回首页保留且刷新后仍在”以及“明确新对话清空且刷新后仍为空”，没有改变产品的草稿保留行为。
