# 产品流程补全 · 2026-11-10

本轮将八项产品补充接到既有研究流程中，保留官网与工作台原有配色。产品源码 `9eaf433` 已合并并推送 main，官网与工作台均已部署；实际版本和上线验证见[发布记录](product-flow-release-20261110.md)。以下保留本地实现与验收范围。

| 项目 | 用户入口与行为 |
| --- | --- |
| 批准前的决策摘要 | 工作台和定理项目的计划确认区展示目标、起点和任务衔接；再次修改时显示增删、依赖与路线变化。细节默认折叠，批准绑定实际展示的计划版本。 |
| 指导的后续反馈 | 聊天指导回执与定理项目反馈分别展示投递、采纳判断、执行记录及精确节点版本。可展开理由和证据，有明确关联时可跳转到路线节点。 |
| 未完成后的续研究 | 结果区解释每个恢复选项会保留什么、修改什么。操作先准备草稿，提交前展示来源、带入的源码提交和预算前后变化。 |
| 首次任务引导 | 自然语言首页可选择数学命题模板或已有 Lean 草稿，实际填入输入框或打开编辑器，并提供模型配置入口。返访时引导折叠。 |
| 按题组织的研究首页 | 自然语言首页的「我的研究」归集同题运行、对话、陈述及协作项目，显示进展、阻碍和「待我处理」，支持搜索与状态筛选。 |
| 历次研究比较 | 结果页的「历次研究」可对照结果、目标、已检查引理、阻碍、路线、模型、用量和耗时；源码差异单独展开，来源研究可直接打开。 |
| 保存研究成果 | 完整验收结果和无条件通过检查的任务版本均可进入 Library。先核对只读来源、版本和回执，再显式保存私有草稿，之后沿用既有预览、发布和复用流程。 |
| 官网案例阅读导引 | 中英文官网提供入门回放、复杂路线、验收证据三个阅读入口，以及真实加零题的陈述确认交互；确认后可进入已录制回放，退回修改会重新锁定入口。 |

研究首页以精确陈述身份或已有项目绑定归组，标题相同不会自动合并。比较时若原意、Lean 陈述或证明环境不同，会明确提示不计算进展增量；缺失用量显示「未记录」。

指导采纳与执行、完整原题验收分别读取对应记录。没有执行证据时显示「暂无记录」，不从后续成功推断指导已经执行。计划理由没有记录时也不补写。

Library 的完整证明固定最终验收证明、提交及证明摘要；任务成果固定任务版本、完整提交、源码和环境摘要及无条件检查回执。预填请求不创建成果，保存后保留来源回执，发布仍经过既有独立检查。

任务检查可能使用独立投影副本。保存时通过回执中的来源引用核对原源码，通过检查记录核对投影提交，不要求两个提交号相同。来源运行环境摘要与 Lean 依赖摘要分别保留，不互相替代。相关回归使用未改写身份字段的真实记录，并验证身份不匹配时拒绝保存。

## 验证与复现

使用现有真实回放与隔离临时数据、可控运行器验证；未启动真实模型、Lean、邮件或生产写入。自动化覆盖交互行为与布局，不替代真人试用。
