## 真实记录与版本

全局图不根据时间先后推测成果继承。新续跑保存来源的任务版本、提交、源码摘要、环境摘要与文件；服务端从真实保存源码读取并核对。客户端伪造固定身份会被拒绝。原始创建输入与幂等指纹不因补充展示元数据而改变，重放和重启后不会重复创建执行。

旧续跑只有任务与提交、且对应多个保存版本时，明确提示无法唯一定位。没有保存的推导、源码、检查或继承关系会显示缺失；不会补造数学推理或把局部检查当作原题验收。

历史搜索区分同一次观察中同任务的多个版本，读取源码时核对真实字节摘要。检查诊断和旧人工记录单独索引。变化摘要的前后阅读记录固定下来，不用当前任务内容替代历史。

## 账号数据与操作

每次读取历史、变化、批注、草稿和预算都重新检查可见权限。撤销运行或项目权限后，旧深链接不能绕过授权。个人运行后来关联项目，原私人批注与整理不会自动变成项目共享内容。

账号草稿仅保存候选、讨论、议题和回复四类内容，不保存 API Key、密码或连接凭据。保存使用请求标识避免丢响应重试产生重复版本；多个设备从旧版本保存时追加冲突分支。恢复不会自动迁移旧任务基准，不会自动提交、检查、投递或启动运行。

整题预算是规划工具。已有运行的时间和 Token 限额仍在各次运行独立执行；整题余额不会自动终止其他运行。缺失用量与零用量分开显示，人民币与美元不合并成一个金额，未配置单价时保留未计价提示。

准备新尝试复用现有原题与配置冻结流程。自己的运行可以恢复所引用的固定 Library 版本；项目共享运行准备为个人尝试，使用本人的账号配置。超出可用 Token 上限会提示核对，不静默截断，不自动执行。
