# 产品流程补全（二）· 2026-11-10

本轮在 `feat/product-continuity` 补齐十一项产品功能，保留现有品牌配色与研究工作台结构。当前为本地实现和验收，尚未提交、合并或部署；上一轮发布记录不代表这批改动已经上线。

| 项目 | 入口与实际行为 |
| --- | --- |
| 官网按起点进入研究 | 中英文官网提供自然语言与已有 Lean 两种入口。登录保留固定模板、证明环境和语言，填好的草稿直接出现在视野中，提交由用户决定。 |
| 免 Key 参与演练 | `practice.html` 可修改计划、批准指定版本、提交指导、查看采纳或拒绝、交互查看路线与录制回执，并恢复进度、导出记录。明确使用录制证据。 |
| 个人待办 | 「我的研究 → 我的待办」汇集认领、评审、补充材料、邀请及关注更新。「已读」与「已处理」分别保存，点击回到对应题目、运行和任务版本。 |
| 连续任务工作区 | 定理项目的任务区连接认领、候选源码、检查、评审和交接。任务选择同步路线检查器与节点反馈；交接经接收者接受后再转移认领。 |
| 跨研究搜索 | 「我的研究 → 全局搜索」覆盖可见题目、对话正文、任务、引理、路线、已保存知识和 Library 历史版本。消息可精确定位；私有及撤回版本按权限过滤。 |
| 按题用量账本 | 「我的研究 → 用量账本」归集历次尝试，分开记录形式化、证明和讲解。同一形式化只计一次，缺失用量与实际零值分开；用户填写单价后才估算金额。 |
| 研究简报 | 运行菜单或「我的研究 → 研究简报」汇总冻结原题、历次尝试、每步推导与依赖、人工决定、检查和成果。支持数学预览、HTML、Markdown、打印或存为 PDF。有源码提交记录的任务链接保留提交号。 |
| 协作邀请与申请 | 私有项目可邀请并指定角色；公开项目支持申请加入、接受或拒绝。接受前保持原权限边界，处理结果进入待办。 |
| 收藏与专题资料夹 | 「我的研究 → 专题资料夹」整理题目、运行、精确任务版本及 Library 版本，可附私人备注，并把选定的固定成果带入新研究草稿。 |
| Library 版本更新 | Library 支持版本对照、发布更新说明、关注与已读记录；对照声明、前提、依赖、环境和源码，不自动替换旧研究中的固定版本。 |
| 议题与决议 | 定理项目支持议题、回复、方案、证据、关联实际反馈与决议。旧修订的草稿先核对更新后再提交；重新讨论保留既有决议历史。 |

个人数据保存在账号目录内，沿用账号删除清理。共享研究的搜索、用量与简报根据当前成员权限读取，撤销成员权限后立即停止展示。公开非成员只看到已授权的公开概况，不显示成员简报入口。

简报只整理已保存的证据。没有推导、指导处理或用量记录时，不生成填充内容。任务检查、消息投递、指导采纳、实际执行和完整原题验收分别展示；自然语言形式化后的证明通过明确标为 Lean 陈述证明通过，保留题意确认方式。

金额使用用户提供的每百万 Token 综合价，分币种汇总，仅为估算。HTML 导出保留数学排版、移除脚本与交互控件；PDF 通过浏览器打印生成。演练不调用真实求解器，也不产生真实验收结论。

## 验证与复现

全部交互验证使用临时服务、隔离数据和受控运行器，不调用付费模型、真实 Lean 或外部邮件，不读取生产账号会话。

已通过 Web 与官网构建、全部相关类型检查、官网入口 11 个场景、演练 7 个场景、研究空间 4 组中英桌面与手机流程、协作 8 段流程及 3 种入口权限、收藏与版本管理两种宽度、既有产品流程 24 个阶段，以及官网和主题切换回归。

- `bun run build:web`：工作台、演练、研究空间和经典题库构建。
- `bun run typecheck`、`bun run typecheck:web`、`bun run typecheck:site`：根目录、Web 前后端、预览及官网类型检查。
- Research、协作、Library、搜索、用量、权限、会话与国际化的 19 个相关测试文件：280 项通过、1 项跳过。跳过项需要 `THEOREMOS_TEST_WORKER_IMAGE` 执行真实隔离 Lean 检查，本轮不调用该环境。主题存储另有 3 项通过，覆盖存储对象本身抛出 `SecurityError`。
- `bun scripts/test-web-research-entry.ts`：官网入口、验证码登录、语言切换与草稿连续性，包括浏览器禁用本地存储后刷新。
- `bun scripts/test-web-practice.ts`：中英文桌面与手机演练，修改后重新批准、采纳与拒绝、回执、恢复、导出和存储不可用。
- `bun scripts/test-web-research-workspace.ts`：中英各 1440 / 390 宽度，搜索定位、三次尝试用量、单价保存、数学简报、HTML / Markdown / PDF 和精确源码回访。
- `bun scripts/test-web-collaboration-continuity.ts`：8 段协作流程，含版本冲突、决议历史、交接及同任务版本不同提交的回访。
- `bun scripts/test-web-collaboration-entry-permissions.ts`：所有者、只读成员、公开非成员三种入口权限。
- `bun scripts/test-web-research-collections.ts`：1440 / 390 宽度，混合收藏、并发冲突、未确认写入重试、版本比较、更新说明和固定版本复用。
- `bun run test:web-product-flow`：既有完整产品流程，中英桌面及手机共 24 个阶段。
- `bun run test:site`、`node scripts/test-site-research-entry.mjs`：官网交互、公式、导航、回放及新入口。
- `bun scripts/test-web-theme.ts`：明暗主题的初始化、切换、跨标签同步、刷新、对比度、键盘操作和登录页；同步更新了旧路线图选择器。

本地证据目录：

- `out/product-continuity/entry/`：官网到工作台的入口与登录。
- `out/product-continuity/practice/`、`site/`：公开演练与官网入口。
- `out/product-continuity/workspace/`：研究空间四组流程及导出文件。
- `out/product-continuity/collaboration/`、`collaboration-entry-permissions/`：协作与入口权限。
- `out/research-collections/`：收藏、Library 版本与更新。
- `out/product-flow/workbench/`：既有流程回归；英文手机导航的修复前后证据位于 `library-nav-focused/`。

新增入口和数据聚合均位于可选 Web 服务，不改变 CLI 与数学运行时的依赖、冻结身份或独立验收机制。
