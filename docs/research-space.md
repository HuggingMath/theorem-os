# 研究空间的三个入口

数学家、定理和 Library 从工作台顶栏进入。目录是各页的默认内容；打开具体对象后，可返回原来的搜索和筛选结果。

| 页面 | 先看什么 | 打开详情后 |
| --- | --- | --- |
| 数学家 `people.html` | 姓名、研究方向、简介及可见的研究与贡献预览 | 同行的研究与实际贡献；自己的未读更新和最近研究优先展示，资料设置随后 |
| 定理 `theorems.html` | 全部已解决的 OpenAI 题目，按完成时间排序；可切换到研究项目 | 查看原题、解题过程、证明源码与验收证据；研究项目保留陈述、进展、讨论和参与者 |
| Library `library.html` | 可复用的 Lean 数学库、定理与定义接口，以及共享数学库、Agent、Skill | 查看模块接口、依赖、来源与源码，或选择已发布固定版本用于新研究 |

数学家目录不自动打开自己的资料。「我的主页」使用明确的个人链接；「我的 Agent 与 Skill」进入个人 Agent 分类，可切换到 Skill。

手机工作台用「研究空间」菜单完整列出工作台、定理、数学家和 Library；研究页保持相同顺序，原对话或运行会随导航传递。登录后回到原页的搜索、筛选、页码与片段，创建入口继续打开表单，关注、添加成员与创建均仍由用户明确提交。

数学家目录的领域筛选忽略首尾空格和英文大小写，提供真实已有领域候选，目录与主页的领域标签也可直接筛选。从同行主页点击「添加到我的题目」，先选择自己有管理权限的项目，再前往成员表单；成员与键盘焦点预填好，只有保存后才写入。

新建定理和创建资源使用独立内容区，收起再打开保留当前表单。目录搜索、领域、类型等条件写入本页 URL，打开详情、返回目录或刷新后可继续浏览。

定理页默认展示全部本地验收通过的 OpenAI 题目，当前快照共 18 道，按完成时间从新到旧排列，包含新近通过的 ThreeStateTreeClauses 和历史通过的 CharacterVarietiesAllSeamsSupport。题目可按名称、目标声明和领域查找，每题提供解题过程、证明源码和验收证据入口；不需要先发布为个人成果。目录读取构建生成的轻量 `classics/data/index.json`，完整源码与研究过程按需加载。已通过的历史运行保留其固定证明、运行和收据身份，后续失败的运行不会将其移出已解决列表。切换到「研究项目」后浏览协作研究，创建题目、陈述版本、绑定运行与讨论流程沿用原有功能。

桌面使用领域侧栏与单列题目列表，手机通过原生下拉选择完整领域，显示各领域匹配数量与当前选择；每题优先展示结论摘要和「阅读解答」，Lean 证明与验收记录为相邻入口。「题目概览」可原位展开完整摘要与本次接受的证明目标，Lean 原题在新标签页打开；概览直接使用轻量目录数据，不额外加载完整源码或过程。支持按中英文数学摘要检索，领域数量随搜索结果更新，没有结果的非选中领域暂不可选；当前选中领域及清除入口保持可用。支持按完成时间或本地化题目名称排列，名称排序写入 URL；清除筛选同时清空搜索和领域，并将键盘焦点放回搜索框。在「已解决题目」和「研究项目」之间切换时，分别保留本次页面内的检索条件和页码；重复点击当前集合保持条件。刷新仍按当前 URL 恢复。

「阅读解答」直接进入证明阅读视图，优先展示本地化题名、问题与结论及当前接受证明。目录提前区分 16 道逐步讲解和 2 道源码阅读，分类与阅读页使用相同的接受运行、证明摘要和检查依据。源码阅读使用真实目标声明名，并提供可展开定位的辅助声明。手机压缩重复导航，尽早显示数学步骤；数学内容与证据保持完整。从阅读页返回目录时保留搜索、领域、排序、页码，并定位原卡片；刷新、切语言和切标签后仍可返回。历史轮次、路线图、完整源码和验收记录仍可打开，旧链接继续可用。

阅读页的「以此题开始研究」和项目陈述版本的研究入口携带固定源码身份。工作台校验来源后先展示原题，用户点击「加入草稿」才追加到已有输入，不发送、不启动运行；随后可自由修改。完整 Lean 原题可展开或复制；超过输入容量的原题如实保留在固定来源中，草稿包含说明、全部证明目标、来源与摘要，不截断源码或目标。失败与取消均保留原草稿，成功后刷新不重复追加。

Library 默认展示服务实际使用的固定版本 Lean 数学库，默认版本包含 53 个模块和 1,964 个定理、定义接口。已有库不需要创建账号、导入个人空间或发布研究成果就可以浏览。53 个模块均提供依据实际接口整理的中英文数学名称和内容简介；完整 Lean 名称、导入语句和接口预览默认收在可展开区域，便于连续浏览。名称与简介也参与搜索。有限的中英文数学概念在本地分词匹配，支持「求递推数列的和」「递推数列求和」和「尾概率 独立」等表达及词序变化，不需要模型；未知额外关键词仍参与限制，精确 Lean 接口检索保持可用。无结果时提供可点击的相关主题。搜索命中模块主题时打开概览，命中具体接口时模块主链接直接定位首个匹配声明。分页打开模块后可以查看全部接口、依赖、来源，并按需读取完整源码。目录、模块和源码保留相同版本摘要；源码对象按其摘要校验，目录或源码不可用时显示错误和重试入口。旧 `library.html?collection=openai` 链接自动转到定理页，并保留搜索词与领域。

接口详情从固定声明中拆出条件、参数与结论，常用接口另附依据对应声明编写的数学说明；完整 Lean 签名仍可展开。每条接口提供准确的 `import`、`#check` 和 `#check @` 用法，后者可查看模块上下文中的隐式参数。这些是接口读取示例，未将其声称为本轮执行过的 Lean 证明。数学库、共享库、Agent、Skill 分别记住本账号在当前标签页内的搜索与筛选，重复点击当前分类不清空内容；分类导航和模块返回保留来源对话，返回目录定位原模块。

模块内搜索同时匹配现有中英文数学说明、条件和结论，不增加 HTTP 请求。条件的解释与对应数学表达式分行显示，`import` / `#check` 最小用法默认折叠，需要时展开。

数学库、Agent 与 Skill 使用紧凑分类导航。数学库目录按领域浏览单列模块，每项包含真实名称、接口数量与预览；可复制导入语句。手机可直接从完整领域列表选择，所选领域持续显示；目录提供「清除筛选」，同时重置关键词、领域、证明环境与页码并回焦搜索，保留个人资源及来源对话。无结果时显示恢复入口和数学用语示例。模块详情支持在当前模块中搜索接口、按引理或定义筛选，并一键清除筛选后回到搜索框。模块内的关键词和类型分别写入 URL 的 `interfaceQuery`、`interfaceKind`，刷新后恢复，目录的关键词、领域和页码独立保留；清除模块筛选同时移除这两个参数。浏览长接口列表时，搜索栏保持可见；固定栏与接口定位的间距随实际导航高度调整，避免遮住标题。页尾可直接返回库目录，或将焦点移回接口搜索。每个接口可复制完整 Lean 名称和固定版本链接，链接保留模块、目录摘要与接口位置，重开或刷新后定位到对应接口；复制失败时提供手动复制说明。完整源码在展开时读取。

「共享数学库」及个人数学资源仍来自研究资源发布系统；它们与已有 Lean 库分别展示。Agent 保存研究配置与协作规则；Skill 补充具体情境下的步骤和要求。个人草稿与已发布版本分别标明，只有可用的固定版本提供新研究入口。撤回版本仍可按权限查看，不能加入新的研究配置。库中存在某条接口不表示它已经证明当前研究目标，实际复用仍走既有的按需装库和独立检查流程。

每个已有 Lean 库接口提供「在工作台引用」。工作台先读取该固定版本的真实接口，再将模块导入、`#check`、接口类型与来源追加到输入框，保留未发送的草稿。从当前对话的 Library 导航进入时，引用会带回同一对话；直接浏览库则加入新题目的草稿。此操作不发送消息或启动研究；读取失败保留原输入并显示错误，成功后刷新不重复追加。

实时工作区在代码出现时即可复制或下载当前查看的原始源码，不需要等待审核结束。手机从对话中的「查看当前代码」进入，也可点击检查记录定位对应版本；关闭代码后回到原对话，保留未发送草稿。选择历史检查时导出相应版本；截断内容标为「源码片段」，使用片段按钮和 `.partial.txt` 文件名。Lean 检查、候选和验收状态仍独立展示，复制失败提供手动复制提示。对话用「已有成果／当前进展／需要你做」说明当前状态，历史记录显示实际状态与更新时间。

各研究入口的时间、Token 与研究轮次默认留空，留空或填 0 表示不限；填写正数时执行原有范围验证及相应限制。草稿与刷新保留不限设置，无限任务不附加隐式的运行超时或轮次上限，用户仍可主动停止。

定理页的运行状态来自绑定运行，不把运行结束解释为完整原题验收通过。陈述版本、Lean 源码、来源和检查证据仍可展开查看，已有运行的固定身份和授权规则沿用原流程。

研究页筛选、数学家主页、项目正文与数学库来源链接会保留原对话；项目关联运行与工作台返回来源分别处理。姓名搜索和领域使用同一份筛选条件。首次个人主页提供完善资料入口，新建且没有陈述的项目直接展开首个陈述编辑器。缺少 API Key 时可从输入框旁直接进入并聚焦设置，题目草稿保留。

详细解答区区分未生成、排队、撰写或核对中、失败、已停止及当前不可用；生成中的讲解在后台刷新，完成后直接显示。数学进展先呈现当前障碍与目标，再列已检查引理，候选提交和待证前提各自标明。结果保留解答与验收证明入口，报告、复核包、分享和归档收在「更多结果操作」。数学库的全部 195 个定义展示经固定源码校验的正文、原作者注释和作用域参数；接口标题及固定链接保留模块内筛选，手机首屏优先展示实际数学结论。定理阅读只需展开一次即可查看完整题意与符号，每步和源码声明可复制定位链接或开始研究，返回来源时恢复绑定同一证明版本的阅读位置及目录来路。

前三组目录脚本均覆盖桌面 1440px、手机 390px 的中英文完整流程，并补充中英文 320px 布局和键盘操作检查。OpenAI 脚本连接真实本地 HTTP 服务，逐题核对完整题目集合、原题、证明、验收和过程文件的摘要与成功运行，验证排序、数学摘要检索、概览目标清单、键盘展开、领域筛选、清除筛选后的键盘焦点、详情入口，以及旧 Library 链接迁移。研究空间脚本使用本地模拟 API，覆盖目录、详情、筛选返回、草稿保留和版本可用性。Lean 库脚本连接真实本地 HTTP 服务、仓库中的固定库目录和空的临时账号数据，验证 Library 默认展示可复用库，没有任何已发布成果时仍能搜索、分页和读取源码；通过浏览器剪贴板核对导入语句、完整 Lean 名称和接口固定链接，验证复制失败提示、链接重载定位、筛选清除回焦，以及本地接口筛选不产生额外 HTTP 请求。这些检查均不调用模型或执行 Lean，时间、Token 与轮数不设上限。实现及权限说明见[数学协作交付记录](collaborative-research-implementation.md)。

Library 引用专项通过真实本地 HTTP 与临时对话记录验证 home/chat 草稿保留、固定接口读取、刷新去重和错误版本反馈。实时代码操作专项通过只读 API 记录回放，核对真实浏览器剪贴板、下载字节、历史版本、截断片段和失败提示；两组都不启动研究任务，等待期限为 0，不设 Token 或轮数上限。
